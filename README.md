# 🇮🇳 Indian States Trivia Quiz App

An interactive, dynamic, and educational web application built with Python and Streamlit that quizzes users on their knowledge of Indian states. 

This project was built as a Python assignment focusing on state management (`st.session_state`), environment variable security, and dynamic user interfaces.

---

## ✨ Features

*   **Dynamic Question Pooling:** The app pulls a random sample of 5 unique questions from an expanded question pool every round. You will get a fresh set of questions every time you play!
*   **Encouraging User Experience:** Displays supportive messages and motivational feedback based on your performance.
*   **Live Scorecard & Feedback:** Instantly tracks your current question and total score, showing interactive floating celebrations (balloons!) upon completion.
*   **Comprehensive Answer Review:** Missed a question? The app features an interactive expander breakdown at the end showing exactly what you answered versus the correct answer.
*   **Secure Infrastructure:** Designed to keep sensitive variables decoupled from the source code using standard Python environment practices.

---

## 🛠️ Tech Stack & Concepts Used

*   **Frontend/UI:** [Streamlit](https://streamlit.io/)
*   **Language:** Python 3.x
*   **State Management:** `st.session_state` to retain data persistently across component reruns.
*   **Security Configuration:** `python-dotenv` and `.gitignore` integration to secure API keys/credentials away from public version control.
